Fish Discover — Patakaran sa Privacy

Huling na-update: Setyembre 8, 2026

Ang maikling bersyon

Walang account ang Fish Discover, walang pag-sign-in, walang ad, walang analytics, walang tracking, at walang server ng developer. Ganap na gumagana ang pagkakakilanlan sa device na ito gamit ang isang modelong naka-bundle sa loob ng app. Hindi ina-upload ng pagtutugma ng larawan ang iyong mga larawan sa developer. Ang mga backup ng device at mga file na pinili mong i-export o ibahagi ay hiwalay na pinangangasiwaan. Kung makikipag-ugnayan ka sa suporta, matatanggap ng developer ang impormasyong pipiliin mong ipadala.

Ano ang iniimbak ng app, at saan

Mga larawang pipiliin o kukunan mo, ang mga species na tumutugma sa ipinapakita para sa kanila, anumang bagay na ise-save mo sa iyong log ng pagmamasid, at ang iyong mga setting ay nakaimbak sa iyong device. Hindi bina-back up ng app ang mga ito sa isang server ng developer. Maaaring mapanatili ng mga backup o paglilipat ng device ang data ng app ayon sa mga setting ng iyong operating system. Ang mga na-export o nakabahaging kopya ay mananatili saanman mo i-save o ipadala ang mga ito. Ang mga Apple device ay nagpapanatili din ng mga trial at purchase-access na talaan sa Keychain; maaaring manatili ang mga tala na iyon pagkatapos tanggalin ang app. Ang pagtanggal sa app ay hindi kinakailangang mag-alis ng mga backup, pag-export, o mga tala ng Keychain.

Camera at photo library

Ginagamit ang access sa camera para sa isang layunin: para hayaan kang kunan ng larawan ang mga isda para makapagmungkahi ang app ng a tugma. Ginagamit lang ang access sa photo library upang hayaan kang pumili ng isang umiiral na larawan para sa parehong layunin. Hindi ini-scan, ini-index, o ina-upload ng app ang iyong library ng larawan.

Access sa network — tumpak na nakasaad

Gumagana ang pagtutugma ng larawan sa device nang hindi ipinapadala ang iyong larawan sa developer. Maaaring gamitin ng mga serbisyo ng Apple StoreKit at Google Play ang network upang mag-load ng impormasyon ng produkto, magproseso ng mga pagbili, mag-restore ng access, o maghatid ng mga asset ng app. Maaaring mag-load ang impormasyon ng produkto bago mo piliing bumili o mag-restore. Ang pagbubukas ng patakaran o mga link ng suporta, pagpapadala ng email ng suporta, at pagbabahagi ng mga file ay gumagamit ng mga serbisyong pipiliin mo.

Mga pagbili

Ang Fish Discover ay libre upang i-download na may 3 araw na ganap na pag-access. Simula sa pag-access na iyon lokal na nangyayari ang window sa iyong device at hindi gumagawa ng subscription o singil. Pagkatapos ng 3 araw, isang opsyonal na isang beses na pagbili ang permanenteng magbubukas sa app — meron walang subscription at walang auto-renew. Ang pagbili o pag-restore na iyon ay ganap na pinangangasiwaan ng App Store o Google Play ng Apple sa pamamagitan ng sarili nilang in-app na pagbili mga sistema. Hindi natatanggap ng app ang mga detalye ng iyong payment-card mula sa tindahan. Nakakatulong ang mga lokal na rekord ng pagbili at pagsubok na pamahalaan ang pag-access. Sa Android, binibigyan din ng valid na access code ang lahat ng feature nang walang bayad na walang limitasyon sa oras; ang app ay nag-iimbak kung ang code-based na access ay aktibo sa device. Ang pagpipiliang code na ito ay partikular sa Android.

Mga bata

Ang app ay hindi nagpapadala ng mga larawan o talaan ng pagmamasid sa isang developer server at hindi kasama ang advertising o analytics. Ang impormasyong pinili mong ipadala sa suporta ay pinangangasiwaan upang tumugon sa iyong kahilingan.

Para saan ang app na ito

Ang Fish Discover ay isang tulong sa pagkakakilanlan para sa pag-aaral. Maaaring mali ang mga tugma nito. Ito ay hindi isang pangingisda-regulasyon, edibility, o gabay sa kaligtasan. Ang mga limitasyon sa laki, panahon, protektadong species at mga panuntunan sa paghuli ay nag-iiba ayon sa hurisdiksyon at nagbabago sa paglipas ng panahon — tingnan ang iyong lokal na awtoridad. Huwag gamitin ang app na ito upang magpasya kung ang isang isda ay ligtas kainin.
